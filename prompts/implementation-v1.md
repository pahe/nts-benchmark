# Uppgift: implementera RoomBooking från grunden

Du arbetar i en tom och isolerad benchmarkarbetsyta. Läs först `REQUIREMENTS.md` i sin helhet. Implementera därefter hela RoomBooking-lösningen enligt kravspecifikationen.

Arbetsregler:

- Skapa lösningen och all produktionskod i den aktuella arbetsytan.
- Använd .NET 10, ASP.NET Core Blazor Web App med Interactive Server-rendering, Entity Framework Core och SQLite.
- Implementera både Blazor-gränssnittet och HTTP-API:t med ett gemensamt tjänstelager.
- Skapa relevanta automatiska tester enligt kravspecifikationen.
- Ändra eller ta inte bort `REQUIREMENTS.md`.
- Använd inte externa tjänster eller en externt installerad databasserver.
- Gör rimliga tekniska val själv när kravspecifikationen lämnar utrymme för tolkning.
- Arbeta vidare tills lösningen bygger och de tester som kan köras i miljön passerar.
- Dölj inte fel genom att ta bort tester, försvaga validering eller ersätta funktionalitet med statiska svar.

Innan du avslutar ska du köra relevanta bygg- och testkommandon. Sammanfatta sedan vad du har implementerat, vilka verifieringar du utfört och eventuella kvarstående begränsningar.
